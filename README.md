BANDAIのトレーディングカードゲーム「**UNION ARENA（ユニオンアリーナ）**」を、Webブラウザ上で快適に遊べるオープンソースのWebサンドボックス＆P2P対戦シミュレーターです。

ログインやサーバー構築は不要。ブラウザを開くだけで、**一人回し（ソロプレイ練習）** や **友達とのP2Pオンライン通信対戦** をすぐに楽しむことができます。

---

## ✨ 主な特徴

### 1. 全8,500+枚の公式カードデータベース & 高解像度画像
- 公式サイト掲載の全カード情報（コードギアス、呪術廻戦、HUNTER×HUNTER、アイドルマスター、鬼滅の刃、SAKAMOTO DAYSなど多数）を網羅。
- 公式高解像度カード画像・効果テキスト・特徴・トリガー・AP/エナジーを完全収録。

### 2. 反転なし固定視点＆両手札直接操作のシームレス一人回し
- 1Pと2Pが上下に向かい合うテーブルトップ視点で固定（手番交代時に画面が180度反転しません）。
- 両陣営の手札・フィールド・ライフ・山札を直接操作可能。相手手札の開閉トグル付きで、実戦想定の一人回し練習が快適に行えます。

### 3. WebRTC（PeerJS）によるサーバーレスP2Pオンライン対戦
- 部屋を作成して発行されたURLを友達に送るだけで、ブラウザ同士がP2P接続。
- **ホスト権威型（Host-Authoritative）同期**: シャッフル、ダイス、初期手札、ランダム破棄などの乱数判定はホスト側で決定論的に処理され、同期ズレが起きません。
- 相手の手札や裏向きライフ、山札の中身は対戦相手の画面では自動マスキングされ、プライバシーを保護します。

### 4. 公式ルール完全準拠 & スムーズな操作性
- **公式5フェイズ進行**: スタート ➔ 移動 ➔ メイン ➔ アタック ➔ エンド。
- **「次のフェイズ ▶」ボタン**: ポンポンと押すだけで公式フローに沿ってステップ進行（先攻1ターン目のアタック禁止も自動判定）。
- **ターン終了時自動全アクティブ化**: エンドフェイズを押し忘れてターン終了した場合でも、公式ルール通り自陣の全カード・APが自動リロールされます。
- **イベントカード場外直行ルール**: イベントカード使用時はフィールドを経由せず即座に場外へ送られます。
- **ダブルクリック / ワンタップでのレスト・アクティブ切替**: 右クリック不要で素早く戦闘・エナジー発生状態をトグル。
- **キーボードショートカット**: `Space`（次フェイズ/ターン終了）、`Escape`（選択・アタック解除）、`Ctrl+Z` / `Cmd+Z`（Undo）。

### 5. 画面フィット（スクロール不要）モード
- ブラウザの表示領域（100vh）に合わせてカードやスロットのサイズが自動最適化され、**縦スクロールバーなしで盤面全体を見渡せます**。
- 好みに応じて「拡大スクロール表示」とのワンクリック切り替えが可能。

### 6. 公式ルール完全判定 デッキビルダー
- カード名・色・特徴・AP・エナジー・BP・効果テキストによる高精度検索。
- デッキ合計50枚、同一番号カード4枚制限（パラレル版自動合算）、各トリガー枚数上限、同一作品タイトル縛りをリアルタイム判定。
- JSON形式でのエクスポート / インポートに対応。

## 🚀 クイックスタート (ローカル開発)

### 必要要件
- Node.js `^18.0.0` または `^20.0.0`
- npm `^9.0.0` または `^10.0.0`

### 1. リポジトリのクローン & 依存関係のインストール
```bash
git clone https://github.com/zkousei/union-arena-simulator.git
cd union-arena-simulator
npm install
```

### 2. ローカル開発サーバーの起動
```bash
npm run dev
```
ブラウザで `http://localhost:5173` を開きます。

### 3. テストの実行
```bash
npm test
```
全12テストスイート（87テスト）が Vitest により高速実行されます。

### 4. リント・ビルド
```bash
npm run lint          # ESLint チェック
npm run build         # TypeScript型チェック & Viteプロダクションビルド
```

## 🃏 カードデータの更新

公式サイトから最新カードデータを取得・同期する場合：
```bash
npm run sync-cards
```
※ `scripts/sync-official-cards.ts` が公式サイトを巡回し、`src/data/officialCards.json` を更新します。
